Images¶

Good photos make the site. A few simple habits keep them sharp and quick to load.

Before you upload¶

  • Photos as JPG, logos and graphics with transparency as PNG.
  • Size: each image field says how wide the photo should be (for example at least 1200px wide). About twice the width it appears on screen keeps it sharp on high-resolution screens. There's no need to go much bigger: very large files (4000px straight from a camera) only slow the site down. Around 2400px wide is plenty for the widest photos.
  • Shape: most photos are shown in a fixed shape (often 4:3) and cropped to fit. Keep the important part of the picture near the middle.
  • File name: describe the photo, with hyphens instead of spaces, for example gared-graphics-food-trays.jpg. It helps search engines.

Uploading¶

Click Add Image (or Set featured image) in any image field and choose Upload files, or upload several at once under Media → Add New. WordPress automatically makes smaller copies for phones and tablets, so you only upload one version.

Alt text¶

In the Media Library, each image has an Alternative Text box. Describe what the photo shows in a short sentence, for example Printed food trays stacked on a production line. Screen readers read it to visitors who can't see the image, and search engines use it too. Leave it empty only for purely decorative images.

Replacing a photo¶

Pick a new image in the field that shows it (a section, the featured image, or Site settings), then Save. The old image stays in the Media Library; delete it there if it's no longer used anywhere.
